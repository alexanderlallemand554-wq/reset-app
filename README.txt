RESET — iPhone webapp (PWA)

INHOUD
- index.html: de app
- manifest.json: appnaam, kleuren en startscherminstellingen
- sw.js: offline cache voor de appbestanden
- icons/: appiconen

HOE ONLINE ZETTEN MET GITHUB PAGES
1. Maak op github.com een account aan of log in.
2. Maak een nieuwe repository aan, bijvoorbeeld "reset-app". Kies Public.
3. Pak RESET_PWA.zip uit op je computer.
4. Open de repository op GitHub en kies Add file > Upload files.
5. Upload de bestanden en mappen UIT de map RESET_PWA (index.html moet in de hoofdmap van de repository staan).
6. Klik Commit changes.
7. Ga naar Settings > Pages.
8. Bij Build and deployment kies je Deploy from a branch.
9. Kies branch main en folder /(root), klik Save.
10. Wacht tot GitHub de website publiceert. De URL staat bovenaan bij Settings > Pages.
11. Open die URL eerst in Safari op je iPhone.

INSTALLEREN OP IPHONE
1. Open de gepubliceerde URL in Safari (niet in een andere browser).
2. Tik op Deel (vierkantje met pijl omhoog).
3. Scrol naar 'Zet op beginscherm' / 'Add to Home Screen'.
4. Schakel 'Open as Web App' in als die optie verschijnt.
5. Tik op Voeg toe / Add.
6. Zoek het RESET-icoon op je beginscherm en open de app.

PRIVACY EN BEPERKINGEN
- Deze versie bewaart je gewoontes en notities lokaal in de browseropslag op je toestel.
- Er is geen account, synchronisatie of cloudbackup. Verwijder Safari-websitegegevens niet als je je data wilt behouden.
- De app is een PWA/webapp, geen native App Store-app.
- Gebruik HTTPS; GitHub Pages biedt HTTPS voor github.io-sites.
